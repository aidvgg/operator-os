# Product marketing context (router)

This file satisfies the context convention of the vendored copy/SEO/CRO skills (`skills/VENDORED.md`): they read it before asking questions. It is a router, never a data file. Per the one-owner rule it restates no positioning, pricing, or state. Read the owners:

- **Positioning, ICP, offer** - `knowledge/business/outbound-offer.md` (the outbound offer and its opening price) and `knowledge/business/brand_foundation.md` (the brand Q&A).
- **Business profile** - `knowledge/business/operator-business-profile.json`.
- **Voice and copy rules** - `knowledge/voice/copy-rules.md` (no em dashes, dead-easy style, no call mentions before the CTA) and `knowledge/voice/channel-voice.md` (per-channel voice).
- **Pain points and objections** - `knowledge/pain-points/pain-point-bank.md`.
- **Proof** - client work under `knowledge/clients/`. What may be claimed publicly about a given client's work is owned by that client's own `README.md`, never assumed.
- **Pricing** - NEVER from these skills or their examples. Authority: `knowledge/business/outbound-offer.md` plus the client's roadmap file. Any number found elsewhere is historical.

This repo's own doctrine (CLAUDE.md precedence, voice, pricing, send authority) overrides anything a vendored skill's examples model.
